# V2.1 物体级时序与性能优化记录

日期：2026-08-04

## 时序判定

- 固定背景图块相似度改为自适应物体视野。
- 掩膜只用于定位；比较软前景、内部灰度、内部梯度和容错形状。
- 相邻时间点采用全局一对一匹配，低置信候选允许不匹配。
- 保守支持一对多分裂边；分裂、数量/多重性增加是强细胞证据。
- 后期高置信细胞或杂质证据可以沿高置信物体边双向传播。
- 三帧物体内部稳定是强杂质证据；两帧稳定只提供中等证据。
- 时序仅修正条件细胞概率 0.25–0.75 的模糊目标。
- 候选缺失、匹配不足、证据冲突或超出模糊区时严格保留单帧标签。
- 时序修正为细胞时保留该帧自身的单细胞/粘连双细胞/细胞团判定。

## 计算优化

- 无效概率不低于 0.60 的未保护候选不再进入实例分割。
- 高置信非细胞使用轻量轮廓清理；细胞相关目标保留窄带边缘吸附。
- 候选提取、密集候选和实例分割增加输入/配置/模型指纹缓存。
- 基础候选按孔使用 4 个受控线程提取。
- 原图中位数由“每个候选重复计算”改为“每张图计算一次”。
- 每个物体只建立一次描述符，每个时序组件只融合一次。
- 保留 `latest_v2_pre_temporal_predictions.csv`，修改时序策略无需重跑实例分割。
