## 本节点已完成

1. 审核入口新增可编辑的孔级前置筛选：
   - 末点细胞覆盖率严格大于输入值；
   - Day2 杂质数严格小于输入值；
   - Day2 细胞数位于输入的闭区间；
   - 任一条件留空表示不限；筛选只影响审核列表，不修改模型结果；
   - 在板子列表顶部统一设置，不再逐板弹窗；显示任务总命中孔数及每块板命中孔数；
   - 进入单块板后仍可修改本板条件，并显示本板命中孔数；
   - 审核摘要版本升级到 v3，旧缓存自动失效，避免新增指标缺失导致筛选结果为 0。
2. 按孔快速审核新增人工判定标签：
   - `Q`：合格（`approved`）；
   - `W`：待定（`pending`）；
   - `E`：排除（`rejected`）；
   - 默认状态为未判定（`unclassified`），不会计入上述三类；只有人工操作后才进入统计，并可清除标签恢复未判定；
   - 使用现有 `well_screening_reviews` 持久化，兼容离线审核结果导入/导出。
3. 项目入口新增人工判定统计：
   - 板子列表上方显示当前任务合格、待定、排除孔总数；
   - 每块板“结果汇总”中显示该板合格、待定、排除孔数。
4. 审核界面新增按时间点人工修正细胞总数：
   - T0、T1、T2 卡片顶部显示“细胞总数”，左侧减一、右侧加一；
   - 细胞总数位于卡片下方控制行左侧，与右侧缩放比例及视图按钮同一横行，不再堆叠在其上方；
   - 自动总数按单细胞=1、粘连双细胞=2、3+细胞团=3计算；
   - 未进行总数人工修改时，更改目标类型会立即自动重算该时间点总数；
   - 使用加减按钮后切换为“人工”总数，后续目标类型变化不会覆盖人工值；
   - “恢复自动”会清除人工值并重新跟随目标类型计算；
   - 加减与恢复自动采用前端即时更新，350ms 内连续操作合并为一次后台保存；保存报告期间不再锁住加减按钮；
   - 人工总数随数据库及离线审核结果导入/导出持久化。
5. Excel 报告结构调整：
   - `孔结论`后新增`人工判定`列，显示合格/待定/排除；未判定孔留空；
   - 不再导出每个时间点的单细胞、粘连双细胞、细胞团分项个数；
   - 仅保留`T0细胞总数`、`T1细胞总数`、`T2细胞总数`；人工总数优先；
   - 新增`末点细胞覆盖率`和`Day2杂质数`。
